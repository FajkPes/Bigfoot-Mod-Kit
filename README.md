# Bigfoot Mod Kit

A host-controlled mod menu for experimenting with BIGFOOT game settings in private sessions.

## Key features

- Adjust player, Bigfoot, time and loot settings.
- Search settings and save presets.
- Install and remove the mod with the included tools.

## Get started

Download the ZIP from Releases and follow the installation guide. A legitimate Steam copy is required; most gameplay controls require the session host.
